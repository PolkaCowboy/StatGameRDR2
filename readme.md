# RDR2 Stat Game

A simple way to gamify self imposed challenges in Red Dead by manipulating the level of character's three stats.

Currently this only operates on ranks 0-7 as I gave up trying to figure out how to unlock 8-9 programatically. You know, those ranks that require finishing the 9 challenges and buying trapper gear. If you have any of those unlocked this will bump up the stat level if less than 7. 

My [minimal unlock save files](https://codeberg.org/PolkaCowboy/Polka-SaveGames) have no challenges completed if you want to use this as a depraved John or Arthur.
